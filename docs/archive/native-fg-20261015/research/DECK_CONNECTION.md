# Как передать данные с Deck

## Сначала локальный пакет

Скачать [native_fg_probe.py](../tools/native_fg_probe.py) в Downloads. Desktop Mode → Konsole:

```bash
python3 ~/Downloads/native_fg_probe.py --vulkan --out ~/Desktop/gfg-device.zip
```

Передать ZIP в чат. Нужен Python3 из SteamOS, установка пакетов/sudo не требуется. Нет автоматической отправки по сети, поиска ключей/паролей, копирования Steam account данных или изменения настроек игры/TDP. В отчёте только выбранные параметры ОС/GPU/питания, необязательный `vulkaninfo --summary` и хеш инструмента. Если команда отсутствует или запрещена, её статус будет записан вместо выдуманных параметров. GPU power cap не следует путать с общим APU TDP. Текущие readings не заменяют временной профиль.

Пакет автоматически не подтверждает OLED/LCD, если model fields неоднозначны: пользователь указывает модель отдельно. Частота дисплея, active game settings и пользовательский TDP не угадываются.

## Локальный LSFG reference

Используется существующий доверенный MAKO CLI и локальная законная DLL. Инструкция в [oracle](LSFG_REFERENCE_ORACLE.md). Пути нужно взять из установленного движка, а не подставлять предполагаемые. Probe не скачивает новые бинарники. По умолчанию FP32; FP16 включается отдельно. Нельзя запускать тяжёлые сравнения одновременно с игрой и интерпретировать их как изолированную стоимость.

## Интерактивный доступ

В этой сессии ещё нет проверенного SSH endpoint или связанного Deck executor. Для прямого SSH нужна достижимость Deck из облачного окружения через существующий защищённый канал/VPN и отдельный доступ. Сначала проверяется способ соединения; затем можно создать отдельный ключ в среде и передать на Deck только публичную часть. Пароль, приватные ключи и Steam credentials в чат не передаются. Один лишь локальный адрес `192.168.*` из домашней сети обычно недостижим из облака.

Текущий рабочий способ — файлы со стенда. Он позволяет исследовать реальные результаты без открытия порта в интернет. Исполнение probe на cloud host проверяет упаковку/ошибки инструмента и не является испытанием Steam Deck.
