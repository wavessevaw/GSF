# Прямой доступ к Deck

Пользователь разрешил временный интерактивный доступ и запросил одну команду для Konsole. Целевое устройство не подключено к executor этой сессии.

Проверены `ssh.tmate.io:22` и `https://tmate.io`: в cloud environment прямое DNS/SSH соединение недоступно, HTTP proxy возвращает `403 Forbidden`. Дополнительное сетевое разрешение было предоставлено, но результат повторного соединения не изменился. Это наблюдаемый сетевой блок окружения; отказа automatic approval review не было.

Команда установки tmate на Deck не устранит этот блок. Поэтому пользователю не предложено выполнять заведомо бесполезную настройку SSH или открывать порт роутера. Ни tmate, ни sshd на устройстве этой сессией не устанавливались/не включались; ключи/пароли не запрашивались.

Рабочие варианты требуют либо execution environment с разрешённым сетевым маршрутом до устройства, либо отдельного локального агента на Deck. Локальный агент будет другой сессией, а не автоматически этим cloud agent. До изменения среды исследование открытого кода и подготовка воспроизводимых экспериментов продолжаются автономно. Пользовательский inventory уже получен и проверен; аппаратные FG результаты остаются NOT TESTED.
