# Неопубликованный async/HDR checkpoint

Запланированная публикация отменена новой директивой владельца. Ни релиза, ни мержа нет. Ниже — состав исследовательских изменений, а не готовность продукта.
Цель: 30 настоящих → 90 отображаемых FPS на Steam Deck OLED при 90 Гц.

Исправления по последним логам Witcher 3:

- Асинхронный вывод: отдельный поток, одно выполняемое и одно ожидающее задание. Короткое ожидание свободных изображений и GPU-буферов перенесено в поток вывода. Очередь не растёт без ограничения; устаревшие пары не генерируются.
- Ожидания игровых семафоров ставятся в GPU-очередь до возврата из Present. Вывод использует собственные семафоры; обращения игры и генератора к очереди сериализованы. Метаданные настоящего кадра, ID и fences сохраняются в собственной копии.
- MAILBOX/IMMEDIATE в активном асинхронном режиме заменяются на FIFO, чтобы промежуточные кадры не отбрасывались самим MAILBOX. Оригинальные структуры приложения не меняются. При невозможности безопасного создания сохраняется исходный swapchain.
- 10-битные A2B10G10R10/A2R10G10B10 обрабатываются непосредственно на GPU с выходами FP16 и окончательным преобразованием обратно в исходный формат, без промежуточного SDR8. Требуемые возможности форматов проверяются; неподдерживаемый вариант сохраняет настоящие кадры. Colorspace и HDR metadata приложения сохраняются.
- Исправлено смешивание соседних пикселей на краю статичного HDR-кадра. Начальный кадр и восстановление истории обходятся без расчёта двух неиспользуемых повторов.

Установка: распаковать основной ZIP и выполнить `bash install.sh` из папки `GFG-Native-FG`.
Параметры запуска Steam: `~/.local/bin/gfg-native %command%`.
Обычный запуск не включает сбор диагностического архива. Для отключения: `~/.local/bin/gfg-native --off %command%`.
Откат: `bash rollback.sh`; удаление: `bash uninstall.sh`.

Целевой режим: экран 90 Гц; настоящие кадры ограничены до 30 средствами игры.
Отдельный лимит 30 FPS в Steam/Gamescope ограничивает также вывод генератора.
Поддерживаются 64-битные Vulkan/Proton-игры с совместимой compute/present очередью.

Предел подтверждения: программные тесты проверяют различающиеся G1/G2, порядок
G1/G2/R, точность поддерживаемого packed10 → FP16 → packed10 пути, синхронизацию,
пересоздание swapchain, восстановление ошибок, установку и воспроизводимость.
Это **не аппаратная приёмка**: физические 90 FPS, игровое качество в динамике,
input-to-display latency, добавочная мощность и длительная стабильность на OLED
пока не подтверждены. Задача #132 остаётся открытой. Пре-релиз не объявляется
законченной реализацией целевого продукта.
