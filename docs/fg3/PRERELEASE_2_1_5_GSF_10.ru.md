# GFG Extreme 2.1.5-gsf.10 — Native GSF ×2 / ×3

Независимый GPU-генератор GFG для Steam Deck. ×2 строит кадр в позиции 1/2;
×3 — два разных кадра в позициях 1/3 и 2/3. Пользователь подтвердил работающий
запуск предыдущей сборки internal.9. В internal.10 сохранён алгоритм генерации; дополнительно исправлены выбор
режима Off при унаследованном XDG_CONFIG_HOME и барьер записи GPU-предиктора.

## Что исправлено

- Автоматическая проверенная установка launcher и компонента при старте Decky,
  корректные Off, откат и запуск при недоступной необязательной диагностике.
- Восстановление цепочки Vulkan loader при повторном создании устройства.
- Реконструкция HDR10 PQ в GPU-кэше линейной яркости вместо смешивания PQ-кодов.
- Передача G1 в WSI до отправки вычисления G2; отмена ненужного G2 при
  обнаруженном дубле, cut или истёкшем сроке. Очистка не ждёт неотправленный fence.
- Упорядочена запись compute в temporal predictor перед перезаписью transfer:
  устранён SYNC-HAZARD-WRITE_AFTER_WRITE, найденный удалённой проверкой.
- Режим Decky сохраняет приоритет при чужом XDG_CONFIG_HOME; явные
  GFG_NATIVE_MODE и GFG_NATIVE_MODE_FILE поддерживаются.

## Проверки и границы результата

Локально проверены полный backend, интерфейс, 17 сценариев Vulkan-конвейера,
HDR/PQ, native-контракты и 14 сценариев непосредственно из итоговых ZIP:
установка, Off с конфликтующим XDG, ×2/×3, порядок G1/G2, Proton metadata,
диагностика и откат. Прежняя internal.9 воспроизводит ошибку выбора Off.
Исходники включены в компонент; GPU ELF собирается против glibc 2.31 SDK; исходники и SHA-256 вложены.
Изначальный кандидат internal.10 с прежней библиотекой не прошёл удалённую
проверку predictor-барьера и не публиковался как GitHub release.

Публикация GitHub Actions разрешена только после повторных проверок backend,
интерфейса, 17 сценариев конвейера, 6 HDR-сценариев и 14 проверок точных ZIP.
Результаты приложены в CI-VALIDATION, локальные результаты — в evidence ZIP.
SHA256SUMS.txt покрывает вложения; исходные установочные ZIP не пересобираются в CI.

**Это pre-release.** Подтверждение пользователем запуска не является измерением
физических 90 FPS. SteamOS/Gamescope/DRM/OLED scanout, стоимость GPU под нагрузкой
игры, качество HDR, задержка и мощность независимо не измерены. Известен пропуск
cut в одной renderer-сцене; универсальная защита от смены сцены не доказана.

## Установка и запуск

Через Decky установите **GFG-Extreme-2.1.5-gsf.10.zip**. После загрузки плагина
native-компонент устанавливается автоматически; начальный режим Off.
Панель: Settings → Diagnostics → GFG Native Generator → Off / ×2 / ×3.
После изменения режима перезапустите игру.

Для отдельной установки возьмите **GFG-Native-FG-v0_0_0-fg3-internal_10.zip**,
распакуйте и выполните `bash install.sh` в каталоге `GFG-Native-FG`.

Параметры запуска Steam для ×3:

```bash
GFG_NATIVE_MODE=3 /home/deck/.local/bin/gfg-native %command%
```

Для ×2 замените `3` на `2`. Для управления режимом из панели Decky используйте
`/home/deck/.local/bin/gfg-native %command%` без явного GFG_NATIVE_MODE.
Для отключения: `/home/deck/.local/bin/gfg-native --off %command%`.
Целевая настройка OLED: 30 FPS внутри игры, экран 90 Гц; общий вывод Gamescope
не ограничивать до 30 FPS. Эти настройки не гарантируют достижение 90 FPS.
Если запуск не работает, полностью очистите параметры Steam для обычного запуска.
