**GSF Kedavra 1.4.1-rc.1 — border stability and smoother pacing. Prerelease.**

- Extend the existing pacing look-ahead to use quarter-speed steps briefly when the remaining ready content would otherwise run out. Use an actually ready half-step if analysis misses its predicted completion. No additional GPU pass or history buffer.
- Scan the scheduler's retained history once per forecast instead of once per forecasted refresh.
- At screen edges, compare source positions against valid texel centres and fade to the available source across the reconstruction footprint. Motion candidates outside the image use their stored residual instead of comparing repeated clamped texels.
- Skip duplicate motion-candidate colour reads and avoid the motion-blur square root on slow/static pixels. The sharp reconstruction filter and motion-analysis resolution are preserved.
- Add four-edge visibility/phase-continuity regression checks and border-only image metrics. Prerelease publication waits for Decky tests as well as the engine and Gamescope runtime jobs, and does not replace the latest stable release.
