**GSF 1.0.0 Kedavra**: x2 / x3 frame generation for Steam Deck in Gaming Mode, inside a patched Gamescope, controlled from Decky. No Lossless Scaling.

Install: Decky → Settings → Developer → Install plugin from zip → `GSF-Kedavra-1.0.0.zip`, then **Setup → Install Gamescope KEDAVRA** and reboot. Details: [README](https://github.com/wavessevaw/GSF/blob/v1.0.0/README.md).

### New in 1.0.0

- **Base FPS slider.** Besides **Auto**, set your own base frame rate from 20 to 90. The engine holds the game there and generation fills the refresh. Rates that do not divide 90 Hz (such as 40) get an exact 2-2-3 cadence from Gamescope's limiter.
- **True game frame rate.** The FPS ring and Auto mode count the game's own frames, also with generation off. Before, the ring could read 90 while the game ran at 25, because Gamescope also flips for the Steam menu.
- **Smoother with an in-game FPS lock.** Frames from a game locked in its own settings keep their place on the cadence grid even when their timing jitters around a vblank (model: uneven outputs 0.96% → 0.11% at a 30 FPS lock). Recommended setup: lock 30 or 45 in the game and pick the same **Custom FPS**.
- **Auto switches faster.** A failed x2 trial now falls back to x3 after a few frames instead of two seconds, and timing jitter that the next frame makes up for no longer counts as a late frame.
- **Less shimmer on stairs and straight lines.** The coarse motion-search levels are filtered so repeating detail no longer folds into moiré that misleads the search. Test stairs scene on lavapipe: 18.1 → 21.6 dB, frame-to-frame change error −44%, with no measurable extra cost.
- **New interface** in green and black, matching GFG Extreme: logo, FPS ring, pace and GPU tiles, Setup, Pace and Log views. The interface, messages and diagnostics are now in English. The HUD uses the same palette.
- **Wider game support.** Games that present 10-bit SDR swapchains (A2R10G10B10 / A2B10G10R10) are now picked up by generation. If a game still is not, the main panel names the rejected Vulkan format and colour space.

### Status

Experimental. The tests above are software results (CI model and lavapipe). The pacing targets (P95 ≤ 1 ms, P99 ≤ 2 ms, < 0.5% missed refreshes) **have not yet been confirmed by a KMS flip trace on a Steam Deck for this version.** Please record a trace in **Pace** and attach it with the diagnostics report when you report results.

**GSF 1.0.0 Kedavra**: генерация кадров x2 / x3 для Steam Deck в игровом режиме внутри пропатченного Gamescope, управление из Decky. Без Lossless Scaling.

Установка: Decky → Настройки → Разработчик → Установить плагин из zip → `GSF-Kedavra-1.0.0.zip`, затем **Setup → Install Gamescope KEDAVRA** и перезагрузка. Подробно: [README](https://github.com/wavessevaw/GSF/blob/v1.0.0/README.ru.md).

### Что нового в 1.0.0

- **Ползунок «Base game FPS».** Кроме **Auto** можно задать свой базовый FPS от 20 до 90. Движок держит игру на нём, генерация заполняет частоту экрана. Для значений, на которые 90 Гц не делится (например 40), ограничитель Gamescope даёт точный шаг 2-2-3.
- **Настоящий FPS игры.** Кольцо FPS и режим **Auto** считают собственные кадры игры, в том числе при выключенной генерации. Раньше кольцо могло показывать 90, когда игра шла на 25, потому что Gamescope переключает кадры и для меню Steam.
- **Плавнее с локом FPS в игре.** Кадры игры с локом в её настройках остаются на сетке лимита, даже когда их время дрожит около vblank (модель: неровное движение 0,96% → 0,11% при локе 30). Рекомендуется: лок 30 или 45 в игре и то же значение в **Custom FPS**.
- **Auto переключается быстрее.** Неудачная проба x2 возвращается на x3 через несколько кадров, а не через две секунды. Дрожание, которое следующий кадр компенсирует, больше не считается опозданием.
- **Меньше мерцания лестниц и прямых линий.** Грубые уровни поиска движения сглаживаются, и повторяющиеся детали больше не превращаются в муар, который сбивает поиск. Тестовая сцена «лестница» на lavapipe: 18,1 → 21,6 дБ, ошибка изменения между кадрами −44%, без заметной добавочной стоимости.
- **Новый интерфейс** в зелёно-чёрных тонах, как у GFG Extreme: логотип, кольцо FPS, плитки темпа и GPU, разделы Setup, Pace и Log. Интерфейс, сообщения и диагностика теперь на английском. HUD в той же палитре.
- **Больше игр.** Игры с 10-битными SDR-swapchain (A2R10G10B10 / A2B10G10R10) теперь берутся генерацией. Если игра всё равно не берётся, главная панель показывает отклонённый формат Vulkan и цветовое пространство.

### Статус

Экспериментально. Цифры выше получены программно (модель в CI и lavapipe). Цели по темпу (P95 ≤ 1 мс, P99 ≤ 2 мс, < 0,5% пропущенных обновлений) **для этой версии ещё не подтверждены трассой KMS flip на Steam Deck.** Запишите трассу в разделе **Pace** и пришлите её вместе с отчётом диагностики.
