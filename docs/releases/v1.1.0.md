**GSF 1.1.0 Kedavra**: x2 / x3 frame generation for Steam Deck in Gaming Mode, inside a patched Gamescope, controlled from Decky. No Lossless Scaling. No launch command.

Install: Decky → Settings → Developer → Install plugin from zip → `GSF-Kedavra-1.1.0.zip`, then **Setup → Reinstall Gamescope KEDAVRA** (or **Install** on a first install) and reboot. Details: [README](https://github.com/wavessevaw/GSF/blob/v1.1.0/README.md).

### New in 1.1.0

- **Smoother fast turns.** The engine now estimates the camera's own motion for every frame pair and offers it to every block, and it starts each search from the previous pair's motion. Blocks on flat or repeating texture no longer land on a wrong match during a fast pan, the main source of the blocky tearing and jitter. lavapipe camera sequence (a pan speeding up to 140 px per frame): 23.2 → 26.3 dB, worst frame 15.7 → 23.2 dB, frame-to-frame change error 12.9 → 5.0. Fast pan 29.2 → 31.2 dB.
- **Walking forward and up stairs.** The camera model includes zoom, so what is near the camera (the bottom and sides of the frame) moves at its own speed instead of the frame's average. New test scene with 5% zoom per frame: 26.2 → 31.2 dB, bottom of the frame 23.7 → 29.4 dB. Fine steps while walking forward are still the hardest case (20.0 dB, unchanged).
- **Auto adapts faster.** Auto keeps only one second of history, retries x2 sooner and at most every 32 s after failures, and starts from scratch for each game instead of carrying the previous one's state.
- **Correct game FPS over the Steam menu.** When Steam's own screen was the base layer, its repaints (90 per second, Steam is not frame-limited) were counted as game frames and generation ran over them. They are now skipped. The status shows `steam_ui` and the app id on screen so a report tells which window it was.
- **New interface.** Roomier layout: one hero card with the FPS ring, the game's FPS and multiplier and PACE / GPU / DISPLAY; an Off / Auto / Custom switch; the base FPS slider only in Custom; Pace, Setup and Log as list rows. Setup folds the checks into one line. Slider and toggle are green.
- **Report on the Desktop.** **Setup → Save report to Desktop** writes one zip (`~/Desktop/GSF-report-….zip`) with the diagnostics, the latest pacing traces and the benchmark.

The analysis costs about the same as in 1.0.0 (camera model: +0.1 ms on lavapipe; not yet timed on the Deck).

### Status

Experimental. The numbers above are software results (CI model and lavapipe). The pacing targets (P95 ≤ 1 ms, P99 ≤ 2 ms, < 0.5% missed refreshes) and the image quality changes **have not yet been confirmed on a Steam Deck for this version.** Please record a trace in **Pace** and send it with **Save report to Desktop** when you report results.

**GSF 1.1.0 Kedavra**: генерация кадров x2 / x3 для Steam Deck в игровом режиме внутри пропатченного Gamescope, управление из Decky. Без Lossless Scaling. Без команд запуска.

Установка: Decky → Настройки → Разработчик → Установить плагин из zip → `GSF-Kedavra-1.1.0.zip`, затем **Setup → Reinstall Gamescope KEDAVRA** (или **Install** при первой установке) и перезагрузка. Подробно: [README](https://github.com/wavessevaw/GSF/blob/v1.1.0/README.ru.md).

### Что нового в 1.1.0

- **Плавнее быстрые повороты.** Движок теперь оценивает движение самой камеры для каждой пары кадров и предлагает его каждому блоку, а поиск начинает с движения прошлой пары. Блоки на однотонной или повторяющейся текстуре больше не цепляются за ложное совпадение при быстром повороте, а это и было главной причиной рваных блоков и дрожания. Сцена «камера» на lavapipe (поворот с разгоном до 140 px за кадр): 23,2 → 26,3 дБ, худший кадр 15,7 → 23,2 дБ, ошибка изменения между кадрами 12,9 → 5,0. Быстрый поворот 29,2 → 31,2 дБ.
- **Ходьба вперёд и по лестнице.** Модель камеры учитывает приближение, поэтому то, что близко к камере (низ и края кадра), движется со своей скоростью, а не со средней по кадру. Новая тестовая сцена с приближением 5% за кадр: 26,2 → 31,2 дБ, низ кадра 23,7 → 29,4 дБ. Мелкие ступени при движении вперёд остаются самым трудным случаем (20,0 дБ, без изменений).
- **Auto подстраивается быстрее.** Auto помнит только последнюю секунду, раньше пробует x2, после неудач пробует не реже раза в 32 с и для каждой игры начинает заново, без истории прошлой.
- **Верный FPS игры над меню Steam.** Когда базовым слоем был экран самого Steam, его перерисовки (90 в секунду, Steam не ограничивается) считались кадрами игры, и генерация шла поверх них. Теперь они пропускаются. В статусе есть `steam_ui` и app id окна на экране, так что отчёт покажет, что это было за окно.
- **Новый интерфейс.** Просторнее: одна главная карточка с кольцом FPS, FPS игры с множителем и PACE / GPU / DISPLAY; переключатель Off / Auto / Custom; ползунок базового FPS только в Custom; Pace, Setup и Log строками списка. В Setup проверки свёрнуты в одну строку. Ползунок и переключатель зелёные.
- **Отчёт на рабочем столе.** **Setup → Save report to Desktop** пишет один zip (`~/Desktop/GSF-report-….zip`) с диагностикой, последними трассами темпа и бенчмарком.

Анализ стоит примерно столько же, сколько в 1.0.0 (модель камеры: +0,1 мс на lavapipe, на Deck ещё не замерено).

### Статус

Экспериментально. Цифры выше получены программно (модель в CI и lavapipe). Цели по темпу (P95 ≤ 1 мс, P99 ≤ 2 мс, < 0,5% пропущенных обновлений) и изменения качества картинки **для этой версии на Steam Deck ещё не подтверждены.** Запишите трассу в **Pace** и пришлите её через **Save report to Desktop**.
