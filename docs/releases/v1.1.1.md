**GSF 1.1.1 Kedavra**: x2 / x3 frame generation for Steam Deck in Gaming Mode, inside a patched Gamescope, controlled from Decky. No Lossless Scaling. No launch command.

Install: Decky → Settings → Developer → Install plugin from zip → `GSF-Kedavra-1.1.1.zip`, then **Setup → Reinstall Gamescope KEDAVRA** and reboot. The zip installs over 1.1.0 in place. Details: [README](https://github.com/wavessevaw/GSF/blob/v1.1.1/README.md).

### New in 1.1.1

- **Fewer square artifacts.** Generated frames now go through a repair chain before they are drawn: two passes over the motion field. A block whose motion disagrees with its neighbours takes a neighbour's motion when that explains the image as well. Wrong motion used to be a whole 4×4 block, which is why the artifacts looked like squares. No added latency.
- **Stairs.** Each block's motion is now checked over a taller window. A vector that jumped over a thin step edge and matched flat stone to flat stone can no longer win, and that is what erased and broke the risers. lavapipe, compared with 1.1.0:
  - climbing big steps (a new scene shaped like the report's photos): 21.9 → 25.3 dB; frame-to-frame change error 4.7 → 3.3
  - slow turn across steps: 26.0 → 29.1 dB, change error 6.5 → 4.9
  - fast steps: change error 10.6 → 10.0
  - walking forward on steps: 20.0 → 21.8 dB
  - The climbing scene is still not better than a plain blend on a single frame pair, so it stays an open case.
- **Steadier camera motion.** Sub-pixel motion and sharper (Catmull-Rom) resampling: the camera sequence goes 25.9 → 27.8 dB, worst frame 23.2 → 23.5 dB, change error 5.7 → 5.2. On a slow pan over plain texture nothing measurable changed (change error 5.45 → 5.43), so fine-texture shimmer on slow turns may remain.
- **Faint motion blur on fast turns.** Only above about 10 px of motion per game frame, at most 4 px long. HUD, text and slow motion are untouched. On sharp test images it costs fast-pan PSNR (31.3 → 28.9 dB) by design.
- **Auto picks the cap from the game's median FPS.** At 90 Hz the caps are 30 / 35 / 40 / 45, so ×3, ×2.6, ×2.25 and ×2. Auto steps up one cap after each clean second. When the game falls behind, it drops to the cap below the median of its frame rate over the last seconds. It never goes above ×3: a game below 30 stays at 30 and frames repeat rather than being stretched further. The HUD shows the fractional multiplier.
- **New panel.** Mode tiles with icons, PACE / GPU / HZ ring cards, a status badge and a status card. Soft glow and gradients, and one layout grid. The focused control is clearly lit for both the stick and the D-pad (Steam's highlight was hidden before). Decky lists the plugin as **GSF Kedavra**.
- **Pacing analyser** reads traces that were cut short instead of failing.

Cost: generating frames costs about 2× the 1.1.0 work on lavapipe (two outputs 44 → 93 ms there). Analysis is unchanged. Not yet timed on the Deck: run **Setup → GPU benchmark** and send the result.

### Status

Experimental. The image numbers above are software results (lavapipe). They **have not been confirmed on a Steam Deck for this version.**

One Deck trace exists from the build installed before this one, believed to be 1.1.0 (Auto, 14 minutes, [evidence](https://github.com/wavessevaw/GSF/tree/v1.1.1/docs/kedavra/evidence/deck-20261021-auto)):
- It met the pacing targets: P95 and P99 interval error a few µs (KMS flips land on vblanks), 0.27% missed refreshes.
- It just missed the uniform-motion check: 0.64% irregular steps, limit 0.5%.

Please record a trace in **Pace** with 1.1.1 and send it with **Save report to Desktop**.

**GSF 1.1.1 Kedavra**: генерация кадров x2 / x3 для Steam Deck в игровом режиме внутри пропатченного Gamescope, управление из Decky. Без Lossless Scaling. Без команд запуска.

Установка: Decky → Настройки → Разработчик → Установить плагин из zip → `GSF-Kedavra-1.1.1.zip`, затем **Setup → Reinstall Gamescope KEDAVRA** и перезагрузка. Zip ставится поверх 1.1.0. Подробно: [README](https://github.com/wavessevaw/GSF/blob/v1.1.1/README.ru.md).

### Что нового в 1.1.1

- **Меньше квадратных артефактов.** Сгенерированный кадр перед выводом проходит цепочку ремонта: два прохода по полю движения. Блок, чей вектор не согласуется с соседями, берёт вектор соседа, если тот объясняет картинку не хуже. Ошибка движения раньше захватывала весь блок 4×4, поэтому артефакты и были квадратными. Задержка не растёт.
- **Лестницы.** Вектор каждого блока теперь проверяется по более высокому окну. Вектор, который перепрыгивал тонкий край ступени и сопоставлял гладкий камень с гладким, больше не выигрывает, а именно это стирало и рвало подступенки. Сравнение с 1.1.0 на lavapipe:
  - подъём по крупным ступеням (новая сцена по вашим фото): 21,9 → 25,3 дБ, ошибка изменения между кадрами 4,7 → 3,3
  - медленный поворот на ступенях: 26,0 → 29,1 дБ, 6,5 → 4,9
  - быстрые ступени: 10,6 → 10,0
  - ходьба вперёд по ступеням: 20,0 → 21,8 дБ
  - Сцена подъёма на одной паре кадров пока не лучше простого смешивания, этот случай остаётся открытым.
- **Ровнее движение камеры.** Субпиксельные векторы и более резкая выборка (Catmull-Rom): сцена «камера» 25,9 → 27,8 дБ, худший кадр 23,2 → 23,5 дБ, ошибка изменения 5,7 → 5,2. На медленном повороте по однотонной текстуре измеримых изменений нет (5,45 → 5,43), так что мерцание мелкой текстуры на медленных поворотах может остаться.
- **Лёгкое размытие при быстром повороте.** Включается только при движении больше примерно 10 px за кадр игры, длина не больше 4 px. HUD, текст и медленное движение не трогаются. На резких тестовых картинках это по замыслу снижает PSNR быстрого поворота (31,3 → 28,9 дБ).
- **Auto выбирает лимит по медиане FPS игры.** При 90 Гц лимиты 30 / 35 / 40 / 45, то есть ×3, ×2,6, ×2,25 и ×2. После каждой ровной секунды Auto пробует лимит выше. Если игра отстаёт, он опускается на лимит под медианой её FPS за последние секунды. Выше ×3 он не идёт никогда: игра ниже 30 остаётся на 30, и кадры повторяются, а не растягиваются сильнее. HUD показывает дробный множитель.
- **Новая панель.** Плитки режимов с иконками, кольца PACE / GPU / HZ, значок состояния и карточка статуса. Мягкое свечение и градиенты, всё на одной сетке. Элемент под курсором хорошо виден и со стиком, и с крестовиной (раньше подсветку Steam закрывал наш фон). В списке Decky плагин называется **GSF Kedavra**.
- **Анализатор темпа** читает обрезанные трассы, а не падает на них.

Стоимость: генерация кадров на lavapipe примерно в 2 раза дороже, чем в 1.1.0 (два кадра 44 → 93 мс). Анализ не изменился. На Deck ещё не замерено: запустите **Setup → GPU benchmark** и пришлите результат.

### Статус

Экспериментально. Цифры качества выше получены программно на lavapipe. **Для этой версии на Steam Deck они не подтверждены.**

Есть одна трасса с Deck на предыдущей установленной сборке, по всей видимости 1.1.0 (Auto, 14 минут, [данные](https://github.com/wavessevaw/GSF/tree/v1.1.1/docs/kedavra/evidence/deck-20261021-auto)):
- Цели по темпу выполнены: ошибка интервала по P95 и P99 составила несколько мкс (KMS flip ложится на vblank), пропущено 0,27% обновлений.
- Проверка равномерности движения не пройдена совсем немного: 0,64% неровных шагов при пороге 0,5%.

Запишите трассу в **Pace** на 1.1.1 и пришлите её через **Save report to Desktop**.
