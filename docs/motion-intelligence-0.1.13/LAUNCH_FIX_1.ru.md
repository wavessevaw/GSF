# 0.1.13 Launch fix 1

Пользователь сообщил, что нажатие кнопки включения ничего не делает. В прежней
панели результат находился внизу длинного списка настроек, а включение зависело
от Steam AppDetails. Без Steam Deck точная причина этого конкретного случая
не установлена.

В этой сборке кнопки запуска и результат операции находятся сверху. Нажатие
показывает немедленное уведомление. Ошибки Steam предлагают ручной запуск,
вызовы Decky ограничены 15 секундами. Ошибка освобождения подписки Steam больше
не оставляет Promise незавершённым.

## Ручное подключение

1. Выберите игру и нажмите **Ручной запуск · показать команду**.
2. Нажмите **Скопировать команду запуска**. При отказе Clipboard API используется
   резервное копирование; если Steam запретил оба способа, показывается ошибка.
3. Вставьте показанную команду в Steam → Свойства игры → Параметры запуска.
   Сохраните имеющиеся параметры: префикс `python3 … --appid … -- ` вставляется
   перед единственным `%command%`. Уберите другой генератор кадров.
4. Выберите ×2/×3/×4, буфер и качество, затем перезапустите игру.

Ручная подготовка активирует только профиль launcher. Она не пишет параметры
Steam и не сообщает, что Steam принял команду. Генерация подтверждается
прежними живыми WSI-счётчиками. Неизвестные исходные параметры Steam не
заменяются пустой строкой при отключении. При ручном отключении префикс
нужно удалить самостоятельно; launcher без активного профиля пропускает игру.

## Проверки

TypeScript, сборка Rollup, тесты Steam API/Clipboard и тест поставляемой панели
прошли. Тест панели проверяет недоступный Steam API, видимую ошибку,
освобождение кнопок, ручную подготовку, копирование и отключение без записи
в Steam. 41 Python-тест backend прошёл, включая сохранение старых параметров,
неизвестные исходные параметры и переключение ручного режима в автоматический.
Регрессионный тест ошибки unregister проверяет завершение ожидания как по
ответу Steam, так и по тайм-ауту.

`decky/tests/extracted_smoke.py` дополнительно проверяет ручную подготовку через
настоящий распакованный backend и запуск ×4 из такого профиля на Vulkan.
Журнал этого прогона поставляется рядом с ZIP.

Нативный алгоритм и существующие пороги приёмки не изменены. Steam CEF,
физическая кнопка контроллера, буфер обмена и презентация на Deck требуют
аппаратной проверки. Ограничения экспериментального Output Owner сохраняются.
