GSF Motion Intelligence 0.1.13 — Experimental preview

Decky Loader test package with multi-frame ×2/×3/×4 generation, shared Flow Lite 2.0 analysis, reconstruction profiles and buffered output work.

This preview does not complete or qualify the entire 0.1.13 specification. Independent output is opt-in and limited to the supported barrier-only SDR WSI contract. General Gamescope/Proton, HDR and WSI extension compatibility remain unqualified.

Automated software Vulkan and extracted-package checks passed. Steam Deck OLED hardware was unavailable: physical display FPS, source FPS impact, power consumption at 10/15 W and hardware latency have not been measured. The included hardware test protocol describes the remaining validation.
